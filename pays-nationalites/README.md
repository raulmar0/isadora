# Pays et nationalités

Jeu minute pour la classe de français : nommer pays et nationalités. La carte se complète au centre ; les drapeaux autour révèlent le masculin et le féminin. Les pays s’écrivent avec leur article.

**Jouer (une fois publié) : https://isadoragazzi.com/pays/**

## Développement

```sh
npm ci
npm run dev
npm test
npm run build
```

Application statique HTML/CSS/JS avec Vite (`base: './'`). Aucun backend.
