# Direction — Un petit monde

## Purpose and first viewport
An immersive, immediately usable directory for Isadora Gazzi's French students. The viewport contains her identity, the greeting « Bonjour, la curiosité. », an actual rotatable Three.js francophone miniature, and the one published game. No invented games or learning claims. The game stays accessible without WebGL.

## Visual world
A tactile miniature atlas: sculpted cream stone, warm yellow, blue ink, miniature Paris, Québec and Dakar. Soft offset shadows. Self-hosted Fraunces display with DM Sans utility typography. The francophone world is wider than Paris.

## Signature interaction
The visitor drags a real 3D island around its vertical axis. The island quietly floats; pause and reset are ordinary semantic buttons. Reduced motion disables automatic animation. Vertical scrolling remains available on touch devices.

## Directory behavior
One clear game card is one link. Future apps are added in src/activities.ts. Future content is communicated by one quiet noninteractive line, not empty app buttons. The game remains local at /quiestce/ using its original source recovered from the existing project backup.

## Implementation choices
Code-first for this session to implement the user's explicit actual-3D request. No standing workflow preference has been recorded. ES/FR UI, default ES, is an implementation assumption. No additional design-approval round was introduced because the user's implementation request already authorizes reversible work.

## Impeccable direction exploration
FORM: miniature atlas. Direction seed `395d987e`, generated with `impeccable concept-seed --scope direction --mode experience`; assigned index 4. No approved comparison comp or quality-bar image was used for the user-pinned real-time 3D implementation.

Grounded possibilities: illustrated francophone travel journal; classroom wooden game board; typographic French bookshop; tactile miniature atlas; letterpress correspondence; Québécois botanical conservatory; West African painted toy theatre. The fourth direction is the miniature atlas, consistent with the seed and user brief.
Seven-segment, racing and fluorescent magazine systems lose audience identification and product clarity here: take their state clarity, action hierarchy and typographic confidence, without borrowing their visual language. Fluid ink and weather hall hold immersion but obscure app access: take continuous spatial interaction and atmospheric cohesion. Tile halls hold material commitment but impose unnecessary content panels: retain material consistency in actual 3D geometry.

## Honest limitations
Image generation produces raster artwork and texture maps, not mesh files. All rotatable geometry is built with Three.js. Static generated illustration is the fallback when WebGL is unavailable. The procedural miniature and generated poster are companion artwork, not identical renderings.
